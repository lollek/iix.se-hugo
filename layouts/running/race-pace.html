How predictions are calculated

The calculator uses the Daniels VDOT model. It estimates oxygen cost from running speed and the sustainable fraction of VO2max from duration, then solves each race distance for the selected VDOT.

Riegel predictions use the entered race result directly: t2 = t1(d2 / d1)k. The default exponent k = 1.06 is a general estimate.
